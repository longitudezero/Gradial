# Changelog

All notable user-facing changes to Gradial are recorded here. Gradial uses
[Semantic Versioning](https://semver.org/).

## [0.3.0-beta.1] - 2026-08-15

First public beta.

### Highlights

- Fast four- and eight-direction radial menus with M4/M5 activation.
- Application profiles, action catalog, sequences, onboarding, and complete
  settings editor.
- Keyboard, text, URL, file/folder, executable, window, delay, and sequence
  actions with frozen-target validation and cleanup.
- DPI-aware per-monitor overlays, edge/corner assistance, custom appearance,
  and imported PNG/SVG icons.
- Hybrid continuous input with configurable 160–400 DIP travel.
- Local Lua 5.4 continuous plugins with explicit trust, permissions, bounded
  execution, and four example packages.
- Local privacy-bounded diagnostics, tray health and recovery, and optional
  per-user start at login.

### Beta limitations

- Windows 11 x86-64 only.
- Executable and installer are not Authenticode-signed.
- Physical high-refresh, mixed-DPI, OS-state, participant, and long-duration
  stable-release qualification remains incomplete.
- Displayed-pixel latency is not yet measurable through the current
  transparent overlay presentation path on the qualification machine.
- Plugin installation and updates are manual; plugins must be locally trusted.
